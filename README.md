# University Student Bot

A Telegram bot designed to provide university students with academic
materials, summaries, drawings, schedules, grades, quizzes, search,
AI assistance, and other student services.

## Main Features

- Student stage selection
- Subjects
- Theoretical materials
- Practical materials
- Approved summaries
- Student drawings
- University grades
- Class schedule
- Exam schedule
- Announcements
- Search
- AI assistant
- Question generation
- Student settings
- Admin panel

## Technology

- Python
- python-telegram-bot
- Supabase
- PostgreSQL
- GitHub

## Security

Sensitive credentials must be stored in environment variables.

Never commit real API keys, bot tokens, or passwords to GitHub.
